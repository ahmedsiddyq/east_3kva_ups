# EAST 3 kVA UPS

Reverse-engineering and diagnostic work on an EAST 3 kVA UPS system.

## Overview
This repository documents investigation of the UPS electronics, control hardware, power stages, measurements, and repair/debugging work.

## Focus
- UPS power electronics
- Fault diagnosis and measurements
- Control and protection circuits
- Component identification
- Practical repair and reverse engineering

## Safety
UPS equipment contains hazardous mains and high-energy DC circuits. Testing should only be performed with appropriate isolation, protection, fusing, and measurement equipment.
